Project Overview

What is E-Baby?

E-Baby is a full-stack e-commerce platform built as a final project for the 3rd Year IT program (1st Semester). This project demonstrates the implementation of a complete web application featuring user authentication, role-based dashboards, product management, order processing, and real-time chat functionality.

The platform includes multiple user roles including customers, sellers, riders/delivery personnel, and administrators. It showcases modern web development practices including responsive design, database management, API integration, and server-side logic with Flask/Python.

Key Features

Authentication System

Secure user registration and login with OTP verification, role-based access control for customers, sellers, riders, and admins.

Product Management

Complete CRUD functionality for products. Sellers can manage inventory, set prices, and track sales performance through their dashboard.

Admin Dashboard

Comprehensive admin panel with user management, sales analytics, tax tracking, seller approval system, and real-time reporting.

E-Commerce Features

Full shopping cart, wishlist functionality, product search, category filtering, and secure checkout with order tracking.

Real-Time Chat

Integrated messaging system allowing customers to communicate with sellers and support team in real-time.

Delivery Management

Rider dashboard for order assignment, delivery tracking, and earnings management with order status updates.

Technology Stack

Backend: Flask/Python
Database: MySQL
Frontend: HTML/CSS/JS
