## System Overview

### What is E-Baby?

E-Baby is a comprehensive e-commerce platform specifically designed for baby products. The platform connects:
- **Buyers**: Parents and caregivers purchasing baby products
- **Sellers**: Merchants selling baby products and related items
- **Riders**: Delivery personnel managing order fulfillment
- **Administrators**: Platform managers overseeing users and operations

### Key Features

- Modern, responsive design that works on all devices
- Secure user authentication with OTP email verification
- Advanced map-based address selection (Philippines coverage)
- Order management and tracking system
- Built-in chat communication system
- Document verification for sellers and riders
- Comprehensive admin dashboard with reporting
- Tax management and financial tracking
- 24/7 AI-powered customer service system
- Community guidelines and dispute resolution

### System Requirements

- **Browser**: Chrome, Firefox, Safari, Edge (latest versions recommended)
- **Internet Connection**: Required for all operations
- **JavaScript**: Must be enabled
- **Screen Resolution**: Optimized for 360px and above

## Authentication & Account Management

### Registration Process

#### Step 1: Access Registration
1. Click "Register" on the homepage or auth page
2. You'll see a registration form with a map display

#### Step 2: Enter Basic Information
Fill in the following required fields:

| Field | Description | Format |
|-------|-------------|--------|
| **First Name** | Your first name | Text (required) |
| **Last Name** | Your last name | Text (required) |
| **Email** | Your email address | Valid email format |
| **Password** | Your account password | Min 6 characters |
| **Confirm Password** | Verify your password | Must match password |
| **Phone Number** | Contact number | Valid phone format |
| **User Type** | Account type (Buyer/Seller/Rider) | Dropdown selection |

#### Step 3: Address Selection

**Using the Map (Recommended):**
1. The map displays the Philippines by default
2. Click anywhere on the map to place a marker
3. The system automatically detects your location and populates the address fields
4. Review the detected address in the fields below:
   - Country
   - Region/Province
   - City/Municipality
   - Barangay
   - Street Address
5. Click **"Select This Location"** button (green) to confirm
6. You'll see a confirmation message for 2.5 seconds

**Manual Entry (If Map Fails):**
1. If the map doesn't work, manually type your address in each field:
   - Country
   - Region/Province
   - City/Municipality
   - Barangay
   - Street Address
2. Ensure all fields are filled completely
3. Proceed to next step

#### Step 4: Document Upload (Sellers & Riders Only)

**For Sellers:**
- **ID Document**: Upload a clear photo of a valid ID (PNG, JPG, JPEG)
- **BIR Certificate**: Upload your BIR registration document (PNG, JPG, JPEG)

**For Riders:**
- **ID Document**: Upload a clear photo of a valid ID (PNG, JPG, JPEG)

File size: Max 5MB per document

#### Step 5: Terms & Conditions
- Read the terms and conditions
- Check the checkbox to agree
- This is mandatory for account creation

#### Step 6: Submit Registration
- Click the **"Register"** button
- You'll see a confirmation message
- **Buyers**: Account activated immediately
- **Sellers/Riders**: Account pending admin approval (can take 24-48 hours)

### Login

#### First Time Login
1. Click "Login" on auth page
2. Enter your email address
3. Enter your password
4. Click "Login"

#### Login Status
- **Buyers**: Instant access to dashboard
- **Sellers**: After admin approval, redirected to seller dashboard
- **Riders**: After admin approval, redirected to rider dashboard
- **Pending Approval**: Cannot login until approved

#### Error Messages
| Message | Meaning | Solution |
|---------|---------|----------|
| "Email or Password incorrect" | Invalid credentials | Check email and password spelling |
| "Your account is pending approval" | Not approved yet | Wait for admin approval email (24-48 hours) |
| "Your account has been banned" | Account restricted | Contact ebabyservices@gmail.com |
| "OTP expired" | Code no longer valid | Click 'Resend OTP' to get new code |

### Password Management

#### Forgot Password
1. Click "Forgot Password" on login page
2. Enter your email address
3. Check your email for reset link
4. Click the link and create new password

#### Change Password
1. Login to your account
2. Go to Profile → Change Password
3. Enter your current password
4. Enter your new password
5. Confirm new password
6. Click "Update Password"

**Password Requirements:**
- Minimum 8 characters
- Recommended: Mix of uppercase, lowercase, numbers, special characters
- Never share your password
- Change periodically for security

### Profile Management

#### Update Profile
1. Click on your profile picture (top right)
2. Select "Profile" from dropdown
3. Edit your information:
   - Profile picture
   - Banner image
   - Name and contact details
   - Address
4. Click "Save Changes"

#### View Profile
- Access public profile by clicking username
- Shows:
  - Profile picture and banner
  - Name and contact info
  - User rating (if applicable)
  - Activity history
  - Public listings (if seller)

## Address Selection with Map

### Map Feature Overview

The interactive map in registration helps you:
- Pinpoint your exact location
- Automatically populate address fields
- Verify your address accuracy
- Provide fallback manual entry option

### Using the Map

#### Step 1: Default View
- Map displays Philippines centered
- Search marker appears in center
- Ready for interaction

#### Step 2: Click to Select Location
1. Click anywhere on the map
2. A red marker appears at click location
3. System automatically geocodes the location
4. Address appears in fields below map:
   - Country
   - Region/Province
   - City/Municipality
   - Barangay
   - Street Address

#### Step 3: Verify Address
- Review all populated fields
- Ensure fields are accurate
- Correct any errors manually if needed

#### Step 4: Confirm Selection
- Click green "Select This Location" button
- You'll see a confirmation message
- Message stays for 2.5 seconds
- Coordinates stored for order delivery

### Manual Address Entry (Fallback)

If the map doesn't work or you prefer manual entry:

1. **Country**
   - Type: "Philippines" or your country
   - Required field

2. **Region/Province**
   - Examples: Metro Manila, Cebu, Davao
   - Type full province name
   - Required field

3. **City/Municipality**
   - Examples: Quezon City, Pasay, Makati
   - Type complete city name
   - Required field

4. **Barangay**
   - Smallest administrative division
   - Examples: Barangay 1, Santo Domingo
   - Required field

5. **Street Address**
   - House number, street name, unit number
   - Example: "123 Main St, Unit 4A"
   - Required field

### Troubleshooting Map Issues

#### Map Not Displaying
- Check internet connection
- Refresh browser (F5)
- Try different browser (Chrome, Firefox)
- Clear browser cache

#### Geocoding Not Working
- Use manual address entry instead
- Ensure JavaScript is enabled
- Check if location is in supported region

#### Coordinates Not Saving
- Click "Select This Location" again
- Wait for confirmation message
- Verify button turns green

## Troubleshooting

### Account & Login Issues

#### Cannot Login
**Problem**: "Email or Password incorrect" error

**Solutions**:
1. Verify email spelling (case-sensitive)
2. Reset password if forgotten
3. Check for extra spaces in password
4. Ensure Caps Lock is off
5. Try different browser
6. Clear browser cookies

#### Account Pending Approval
**Problem**: "Your account is pending approval" message

**Solutions**:
1. Wait 24-48 hours for admin review
2. Check email for approval notification
3. Ensure documents were uploaded correctly
4. Contact support if exceeds 48 hours

#### Account Banned
**Problem**: "Your account has been banned" message

**Solutions**:
1. Note the ban reason displayed
2. Contact ebabyservices@gmail.com immediately
3. Read the ban notification email
4. Click "Appeal" link if available
5. Submit detailed appeal with evidence
6. Decision made within 5-7 business days
7. Temporary bans may be lifted after appeal approval

### Registration Issues

#### Document Upload Fails
**Problem**: Cannot upload ID or BIR document

**Solutions**:
1. Verify file format (PNG, JPG, JPEG only)
2. Check file size (max 5MB)
3. Clear browser cache
4. Try different browser
5. Screenshot document instead

#### Map Not Working
**Problem**: Map doesn't load or click doesn't work

**Solutions**:
1. Refresh the page
2. Use manual address entry
3. Check internet connection
4. Try Chrome or Firefox
5. Disable VPN if using one

#### Address Fields Empty
**Problem**: Address fields don't populate after clicking map

**Solutions**:
1. Click on map again
2. Wait 2-3 seconds for geocoding
3. Manually type address
4. Check browser console for errors (F12)

### Browsing & Shopping Issues

#### Products Not Appearing
**Problem**: Search results empty or categories show no items

**Solutions**:
1. Refresh the page
2. Clear search filters
3. Try different category
4. Check internet connection
5. Try incognito/private browsing mode

#### Add to Cart Not Working
**Problem**: Cart doesn't update when clicking add button

**Solutions**:
1. Refresh page
2. Clear browser cache
3. Verify JavaScript enabled
4. Try different browser
5. Check product availability status

#### Checkout Problems
**Problem**: Cannot proceed to checkout or payment fails

**Solutions**:
1. Verify cart isn't empty
2. Confirm address is complete
3. Check internet connection
4. Try refreshing page
5. Contact support if issue persists

### Order Issues

#### Cannot Track Order
**Problem**: Order status not updating or tracking unavailable

**Solutions**:
1. Refresh orders page
2. Wait 1-2 minutes for updates
3. Contact rider directly via chat
4. Check order email for tracking link
5. Contact support with order ID

#### Order Delivery Late
**Problem**: Delivery takes longer than expected

**Solutions**:

2. Check current location on map
3. Verify delivery address is correct
4. Contact seller about order status
5. If extremely delayed, contact support

**Problem**: Cancel button unavailable

**Solutions**:
1. Orders can only cancel in "Pending" or "Processing" status
2. If shipped, contact rider for options
3. Request return after delivery
4. Contact support for special cases
